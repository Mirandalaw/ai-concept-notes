# AI 개념 노트

LLM · RAG · 검색 품질 · 지식 설계 · 운영을 한 장에 정리한 학습 노트입니다.
실제 사내 지식 검색 플랫폼을 만들며 고른 선택과 버린 대안을 함께 적었습니다.

- **195개 항목** / 16개 장
- 항목마다 **개념**과 **실제로 어떻게 썼는지**를 나눠 적었습니다
- 읽은 항목은 브라우저에 체크로 저장됩니다(localStorage)

## 구성

| 트랙 | 장 | 내용 |
|---|---|---|
| AI 기초 | A0–A5 | 머신러닝 → LLM 원리 → 프롬프트 → 에이전트/MCP → 모델 서빙 → RAG·파인튜닝 |
| 검색 품질 | 1–3 | 임베딩·벡터 → 융합·리랭커·MMR → 측정과 함정 |
| 지식 설계 | 4–5 | 데이터 모델 → 관계·그래프 |
| 운영 | 6–9 | 모듈·이벤트 → LLM 활용 → 보안 → 운영 |
| 설계 결정 | D | 무엇을 고르고 무엇을 버렸나 (16건) |

## 읽는 순서

처음이면 **A1 → A5 → D**. 검색을 파고들 거면 **1 → 2 → 3**(측정은 마지막에).
